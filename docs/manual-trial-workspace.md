# 试调、断面与状态工作台（2026-10-16）

本说明更新日常操作；历史库、原交付方案及旧成果继续保留。没有更改产汇流科学公式、删除业务记录或实施Excel自动入库。

## 方案与人工试调

方案管理三个主要部分：洪水与用途、自动率定设置、采用参数。编辑设置先自动暂存草稿，明确保存才更新方案。自动率定有修改时按钮为“保存设置并开始率定”；名称始终由用户定义，历史修订在后台保留。

人工试调有独立的参数、来源、计算范围和浏览器会话暂存。无需先自动率定，也无需保存临时数值为方案。来源按方案采用参数、同条件自动率定结果、方案初值初始化，用户可主动选择模型默认参数、参数库记录或某次自动结果；页面显示实际来源。

1. 打开方案并选择要看的洪水。
2. 切到“人工试调”，确认参数来源，修改产流、坡面或河道数值。
3. 默认试算当前洪水；需要时选择全部已选洪水。连续演算仍从原起点计算，不跳过前期过程。
4. 成功后勾选比较曲线：实测、最近两次成功试调和一份自动率定参考。第三次成功替换最早的人工曲线；失败不替换，历史计算不删除。
5. 选中满意的已完成计算，保存自定义参数名。参数入库并成为方案采用参数，可直接带入洪水模拟。尚未运行的编辑值不会混进该记录。
6. 只有点击“用于自动率定初值”才将参数带回自动设置。保存参数及采用关联均不改洪水划分、算法和原初值。

方案另有未保存洪水或条件修改时，人工可按暂存条件试算，实际选择冻结到计算记录，不顺带保存方案。临时值按工作区、方案及浏览器会话暂存；自动草稿和临时试调不共用修改标记。

比较校验当前过程的边界、驱动资料、前期条件、蒸散发、空间配置和程序；参数差异用于比较，不因此禁止叠加。未计算过的洪水显示提示，不套用其他场的曲线。每条曲线显示时间、指标和参数变化。

载入默认或库参数默认只替换数值。同一区域的“同时采用蒸散发与预热条件”由用户勾选，不再打开背后的第二个窗口。离开先暂存；只有暂存失败可能丢失内容才提示。双页面保存冲突保留先保存内容，不能自动覆盖。

## 图表与洪水目录

图表按实际容器宽度安排时间刻度，日期和小时分行，完整时刻在提示框；图例、轴名、时间标签及缩放条分别留空。相同时段内回放或调整宽度保留已有缩放范围。

雨水情按内容区宽度调整筛选、地图和详情布局；地图卡片有明确高度，详情不把地图撑长。开关详情适配视野，普通回放不重置用户拖动与缩放。雨量数值和缺测语义保持原样。

水文资料库、率定和模拟选洪水使用相同表头：点击排序箭头切换升序、降序、默认，筛选图标设置条件，先全表筛选排序再分页。洪峰按数值排序，空值末尾，同值按时间和标识稳定排序。筛选翻页不会修改选中场次、用途或方案。

## 河道参数

产流、坡面和河道共用参数控件。检查本次实际采用的K、X，仍保留一小时时步条件 `2KX ≤ 1 ≤ 2K(1−X)`，K单位为小时。问题显示在参数区，可只看问题河段、违反条件及固定X时可用K区间。载入对象明确区分同事交付参数、指定自动率定结果和模型默认值；修正只替换当前目标参数区，不改变全局配置。

无效参数只阻止提交对应计算，不阻止看历史或曲线。原交付搜索基准继续按原路径率定，不能将其误当成本次有效直接模拟参数。

## 河网、断面与GIS

“模型与资料 → 河网与断面”包含河网查看、我的断面、GIS图件。这里不再维护另一套全局汇流参数。

断面可独立于计算成果创建：地图点选、查看实际吸附位置及距离、命名保存。位置记录包含点击点、河道点、河段和空间配置；改名不移动位置，移动另存。随后查询流量再选择成果和洪水，从成果进入则带入已有选择。空间配置不匹配须重新定位。

出口直接读取对应过程的保存流量；中间断面复用已有结果，必要时按原条件计算汇流。查询不能静默扩大到其他洪水，结果支持导出。GIS沿用已有地形河网图、汇流分区图两类PNG及GIS成果包，可读取已有成果或生成并下载；不再要求选择旧雨流加工包。

旧诊断链接保留历史查询和成果，已清除其无入口的全局汇流编辑、登记和选用逻辑。

## 过程与状态

主入口“过程与状态”直接提供“模拟过程”和“状态库”。过程顶部选择成果及洪水，雨流过程、时间轴、状态分布同源；区分蓄水状态和产流过程。网格默认箭头，悬停浅色边框，点击持续高亮；仅拖动时显示抓手，切换变量和时刻保留同一网格。

逐时分布属于成果；命名状态库保存完整末状态，用于续算。正在看某场洪水的中间时刻，不能把部分网格数据当成完整初态。连续演算早期评价窗口早于共享末状态时，可“查看完整末状态”，保存显示的真实末时刻；旧成果缺逐时状态时按原条件补算。状态库默认显示已命名状态，提供查看、改名、导出和续算，高级初始化能力收起。

保留原方案、草稿、输入、参数、状态、断面和结果；旧计算读取自己的冻结条件。人工请求复用现有operations，后台接受临时参数并冻结条件；自动率定保持已保存设置校验。方案采用参数独立并发检查、幂等重试；参数保存成功但关联冲突时，保留参数并明确提示补关联。
