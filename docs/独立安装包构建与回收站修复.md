## 清理行为

自产末状态与其生产任务组成一组，不能再把它对生产任务的引用误判成外部依赖。真正被其他计算、已保存参数、命名/收藏状态或方案引用的文件受到保护。

“移入平台回收站”仍只修改记录状态；用户确认从平台回收站移除时，任务和未被引用的自产状态一起送入 Windows 回收站。移走成功后才删除索引；失败会报告并在 `workspace/cleanup-journal` 留下记录。

旧版残留的处理入口是“计算成果 → 回收站 → 检查旧版残留文件”。此入口先列出文件和体积，确认后执行，不自动清理已有工作区。雨水情、输入产品和独立 GIS 图件不在孤儿任务清理范围。

## 构建

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\package_standalone.ps1 -SkipSeed
```
