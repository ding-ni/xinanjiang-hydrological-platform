## 🔍 降雨处理的具体问题

### 全年零值没有经过同等质控

数据库中 `7011AJ72` 古羊岭水库站在2021年和2022年均有8760小时有限值，全部为零。2022-06-05洪水中，该站面积平均IDW权重约27.79%；仅在诊断中排除该站，面雨量从18.43变为22.75 mm，增加约23.4%。2022-04-13为24.64→29.36 mm，2022-03-17为103.83→123.53 mm。

代码链路上，[历史资料准备](../backend/scheme_inputs.py) 将非有限值、负值置为缺测，然后直接调用逐小时IDW；[历史库导入](../backend/hydro_database.py) 保留原零值。另一条[站年质控实现](../backend/vendor/model/code/runoff_platform/data/precipitation_idw.py) 已有可配置的 `sanitize_station_year`，但此次历史库准备路径没有调用它。

这是已确认的路径差异：同一平台的“全年全零”策略没有贯穿本次历史库计算。全年全零记录不应仅因“有限值齐全”就被当成质量已合格。正式修正前应追溯原始资料是否用零表示未启用、停报或未录入，并建立新的资料/处理版本；不能对短洪水窗口简单套用“全零即缺测”，因为局地无雨本身可能是真实的。

### 插值、面积与蒸散发的边界

本次独立按每小时有效站组合、EPSG:32650距离和冻结网格中心重算IDW，能重现原面雨量，说明没有发现当前插值权重或面积汇总的数值映射错误。此前留一站验证中，幂次1/2/3的场均RMSE分别约1.2645/1.3195/1.3856 mm/h；这不足以确定真实面雨量，也不能替代站点质控。

控制面积为63.27190569 km²，质控配置64.1 km²，相差约1.31%，不足以单独解释数十个百分点的水量误差。PET是冻结的逐月气候假设，非实测蒸散发；KC触及0.4下界可能包含对PET、降雨或状态误差的补偿，不能孤立解释为真实流域蒸散发系数。

## ⚙️ 产流、汇流与初态

此前隔离复核已完成三层蒸散发、蓄满产流、不透水面积、自由水与三水源分配、小时系数换算、坡面退水和Muskingum汇流的标量或解析小算例，相关32项真实模型回归及12项最终专项通过。本次逐场核验状态数组与目录的登记摘要，并再次检查16场已保存内部逐时平衡残差，最大约 `5.37e-14 mm`。

同一场与另一场一起计算、各自单独计算，过程、指标和全部末状态差值为0。这支持当前独立场次执行没有跨场传递状态。此前连续整段/分段续算检查也通过。上述证据证明已覆盖情形的数值一致性，不证明站点输入、实测流量或所有现实产流机制都正确。

当前7天预热是近似前期状态的方法，不意味着自然流域在每场洪水前实际重置。固定参数的16场预热实验为：

| 预热 | 平均NSE | 平均绝对水量偏差 |
| --- | ---: | ---: |
| 3天 | 0.6345 | 35.93% |
| 7天 | 0.6588 | 33.94% |
| 14天 | 0.6855 | 30.82% |
| 30天 | 0.6433 | 32.08% |

14天在该组固定参数实验中较好，但没有重新率定，也不构成所有洪水统一改为14天的依据。连续资料完整时，可以用连续轨迹或可信父状态对照独立预热，检查土壤蓄水、自由水、坡面及河道退水是否在事件开始前合理；不应每场用实测洪峰反调初态后再宣称独立预测准确。

## 🎯 率定目标、预算与人工试调

本次启用NSE权重0.5、洪峰误差0.25、峰现误差0.25；水量和KGE未启用。“合格”只依据NSE≥0.5。因而当前结果出现“合格但少算三成水量”，与目标定义并不矛盾，但业务评价仍需同时查看水量和洪峰。

960次评价中724次有效、236次无效，占24.58%。无效原因：

| 原因 | 次数 |
| --- | ---: |
| R0001不满足小时Muskingum非负系数条件 | 206 |
| R0002不满足小时Muskingum非负系数条件 | 22 |
| `WM > WUM+WLM` 或 `KI+KG < 1` 约束不满足 | 8 |

运行终止原因为 `BUDGET_EXHAUSTED`，预算用完不等于已证明收敛。无效候选被拒绝而没有作为可接受洪水成果，说明约束检查起效；大量预算用于无效区域，提示下一步应考虑可行域采样或参数化，而不是放松小时汇流稳定约束。

KC=0.4、B=0.8、IM=0.08、地下水比例=0.02、Muskingum X=0.05等触及边界。多参数补偿的可能性需要与雨量质量、PET假设和初态一起检查；不建议直接扩大所有边界，再用更高NSE认定物理更合理。

两次人工试调都针对2024-06-19：

| 计算 | 改动 | NSE | 水量偏差 | 洪峰偏差 |
| --- | --- | ---: | ---: | ---: |
| 自动率定 | 基准参数 | 0.856155 | -15.81% | -27.34% |
| 13:05:19试调 | 仅WUM：21.5822→35.65 | 0.856140 | -15.81% | -27.34% |
| 13:06:14试调 | 同时改KC、WM、WUM、WLM、SM | 0.475683 | -37.36% | -67.63% |

单改WUM对这场长湿润洪水影响很小，不能外推为WUM对所有洪水无效。第二次同时增加蓄水容量、自由水容量并改蒸散发系数，结果变差，不能把全部变化归因于其中一个参数。更有效的诊断是固定其余参数，一次改一个，并同时看干湿初态、径流分量、水量和峰形。

2024-06-19原标签是独立检验。原自动率定的历史评价保持有效；如果后续根据这场人工试调表现选参数，它将成为后续开发使用过的证据，正式最终检验应另留未用于选择的洪水。

已有三种子同预算对比中，DE的率定目标中位值约-0.2340，SCE-UA约-0.2017，目标越小越好；该960次预算下没有证据支持改用SCE-UA作为默认。应先固定资料、目标和可行域，再评估是否增加预算或采用其他搜索策略。

## ✍️ 建议的收尾顺序

1. 先核对古羊岭2021/2022全年全零，以及宋家垅、麻栗坞等低报时段的原始记录、站号、有效期和质量含义。把“有记录”和“观测可信”分别记录；来源确认后在新资料版本中执行质控，原输入和原结果保留。
2. 在固定参数下比较新旧面雨量及驱动后的过程，重点检查低估严重场，也保留2019、2020已较好场和高估场作为对照。降雨修正效果不能只看最优NSE。
3. 核对事件起始流量、预热雨量和状态，使用7/14天及连续轨迹作受控对照。对可能的实测偏差、洪水边界或水库调蓄分别留证据，不提前归因。
4. 在新的率定方案中明确加入水量目标，冻结权重和样本分组，再改善可行域采样并对等比较搜索预算；不改变当前采用参数。
5. 候选锁定后在未用于人工选参的洪水上做最终验证，分别报告过程、水量、洪峰、峰时和状态合理性。
