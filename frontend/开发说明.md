# Vue 前端开发说明

本目录是统一水文平台的 Vue 3/Vite 前端源码。正式服务由仓库根目录启动器运行，统一后端提供构建网页与同源 `/api/model` 接口；Vite 入口用于本地开发。

## 开发

先按根目录[部署与维护手册](../部署与维护手册.md)安装并启动统一后端，再在本目录执行：

```powershell
npm ci
npm run dev
```

Vite 默认监听 `127.0.0.1:5173`，并将 `/api/model` 请求代理到 `127.0.0.1:8878`。本目录的 `打开开发服务器.bat` 可启动开发入口；正式使用运行仓库根目录的 `启动统一平台.cmd`。

## 检查与构建

```powershell
npm test
npm run build:unified
```

`build:unified` 输出正式统一服务使用的 `dist-unified`。接口契约见[API 文档](../backend/API.md)，平台和运行工作区说明见仓库根目录[README](../README.md)与[操作说明](../方案与自动率定操作说明.md)。

## 案例与资料

新增案例前阅读同目录的[案例包规范](案例包规范.md)和[数据目录说明](数据目录说明.md)。`public/data` 只存放前端需要的清单、轻量空间资料和预览；原始资料、数据库、模型输入、计算状态及成果由后端工作区管理。源码和案例清单不应写入开发者机器的绝对路径。
