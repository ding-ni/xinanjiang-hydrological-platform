# 南安溪-徐畈独立安装包

本安装包面向 Windows 10/11 x64，离线运行。安装后固定使用南安溪-徐畈、1 km 空间分辨率，平台通过本机浏览器打开。

当前修复版为 1.2.4。保留 HDF5 DLL 加载及回收站任务/自产状态联动清理修复，另修复旧页面继续读取已删除计算时出现 status.json 文件不存在的问题：缺失计算返回明确的记录状态，页面移除过期结果与活动任务选择，正常保留参数和方案编辑条件。

“移入平台回收站”只改变保留状态，文件暂时保留；在回收站确认移除后，同一次计算的任务、未被引用的自产状态一起移入 Windows 回收站。系统回收站仍占磁盘空间，不自动清空。已保存参数、命名或收藏状态、后续任务及其他方案的引用会阻止清理，并显示原因。失败时不伪报成功，处理记录保存在 workspace/cleanup-journal。

对于旧版已经删除方案却残留的内部任务，请打开“计算成果 → 回收站 → 检查旧版残留文件”，核对文件清单和体积后确认。此入口仅处理父操作已不存在的内部任务，不清理雨水情、MDB、输入产品、模型/GIS，也不清理独立 GIS 图件任务。升级安装不会自动清理旧工作区。

安装程序使用当前 Windows 用户权限，不需要管理员权限。第一次启动会把只读种子资料复制到安装目录的 `workspace` 子目录；例如安装到 `E:\Nan...` 时，工作区、数据库、模型输入、成果、状态和日志都会在 `E:\Nan...\workspace` 下。若检测到旧版 `%LOCALAPPDATA%\Nananxi-Xufan-Platform\workspace`，新版会先检查服务端口空闲，再复制到安装目录；原 C 盘数据保留不删，供回退核对。安装目录必须允许当前用户写入，建议安装到用户有写权限的数据盘目录，不要放进受保护的 `Program Files`。

右上角“退出平台”只在没有排队、运行或停止中的计算/资料加工任务时关闭服务并释放 8878 端口。卸载程序不会删除安装目录中的 `workspace`，接收方生成的数据需要人工清理时再处理。

打包流程：先运行 `scripts/package_release.ps1`。该脚本会构建专版前端、净化种子库并调用 PyInstaller；最后需要 Inno Setup 的 `ISCC.exe` 编译 `installer/南安溪-徐畈平台.iss`。`scripts/verify_release.py` 可在交付前检查文件摘要及种子库内容。种子目录只作为首次安装复制源，不能直接作为运行工作区。
