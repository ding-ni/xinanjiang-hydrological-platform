# 水文作业工作台

本文说明当前率定、模拟、成果、状态与断面查询的日常操作。工作台读取所选方案和运行工作区；静态案例资料、业务数据库与计算成果各自保持边界。

## 方案与计算

方案管理洪水用途、率定设置和采用参数。查看、筛选和翻页不会修改方案；编辑内容先进入草稿，明确保存后才形成新版本。人工试调使用独立的临时参数与会话草稿，不要求先运行自动率定，也不会自动改变方案。

1. 打开方案，选择洪水和计算方式。
2. 进行人工试调时，确认参数来源与计算范围；默认仅计算当前洪水。连续模拟仍从方案定义的连续起点演算。
3. 成功试调后可叠加实测、最近两次成功试调和一份指定自动率定参考。失败计算不会替换成功曲线或历史记录。
4. 需要复用试调参数时，从已完成记录保存命名参数，再明确设置方案采用参数。设置自动率定初值是另一个独立操作。
5. 自动率定预算耗尽会如实记录终止原因为预算耗尽，不代表搜索已收敛。评价需要同时查看NSE、洪峰、峰时和水量误差。

计算记录保存冻结条件。再次模拟使用固定参数；再次自动率定才会重新搜索。改名、备注或收藏不触发计算，也不改变数值身份。

## 成果、状态与断面

在“计算成果”查看、比较、恢复条件和导出。计算记录关联洪水过程和时刻；已有逐时状态只读。命名的完整末状态可以进入状态库供续算，浏览中的单个时刻或部分网格分布不能代替完整初态。旧成果若缺少当前实现或科学身份，可以查看和导出，但不能直接续算。

河道断面位置独立于计算成果保存。查询流量时明确选择成果、洪水过程和断面；空间配置不匹配时重新定位。出口可读取成果中已有流量，中间断面按原计算条件准备所需汇流。查询不会静默切换洪水或扩大计算时段。

## 案例与资料

浏览器静态目录只提供案例清单、轻量空间资料和预览。原始 MDB、观测库、模型输入、运行状态及计算结果由后端从所选工作区读取。切换案例不会把其他案例的参数、状态草稿或结果借来显示。

历史方案及成果按各自冻结的输入、站网、科学条件、模型实现和起算规则复算。新方案使用当前登记的历史资料与处理规则；资料变化不会静默改写已有成果的输入身份。观测缺测、网格生成失败和率定质量不合格是不同状态，不能互相替代。

## 检查

在 `frontend` 目录运行 `npm test` 与 `npm run build:unified`。后端回归在项目根目录运行 `python -m unittest discover -s backend/tests -q`。浏览器验收应使用隔离工作区和空闲端口，不指向日常业务工作区。
