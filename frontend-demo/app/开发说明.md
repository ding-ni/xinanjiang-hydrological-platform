# 新安江水文模型平台 · Vue 前端 Demo

当前工程保留独立 Demo 模式，也支持统一后端模式。根目录 `启动统一平台.cmd` 构建 dist-unified 并同源提供 `/api/model`；南安溪 1 km 已接入真实模拟、场次率定和状态续算，生产预报仍阻断。当前运行边界以根目录 `统一系统说明.md` 为准。正式 Git 仓库尚未建立。

新增或整理案例前，先阅读同目录的 `案例包规范.md` 和 `数据目录说明.md`。案例必须保持并行、独立，不能把某个案例的盘符路径、数据文件或专用分支复制成全局默认。

## 开发启动

```bash
npm install
npm run dev
```

浏览器访问 `http://127.0.0.1:5173/`。也可在上一级目录双击 `打开平台.bat`。

## 脚本

| 命令 | 说明 |
| --- | --- |
| `npm run dev` | 启动 Vite 开发服务 |
| `npm run build` | 生成生产构建 |
| `npm run preview` | 预览生产构建 |
| `npm test` | 运行前端响应、相对路径、动态案例和无后端边界的单元测试 |

生产构建只表示 Vite 静态文件构建成功，不表示模型计算或后端服务可用。当前不制作 ZIP、EXE 或 Windows 安装器；需要外发时，先确保源码、案例目录、路径解析和启动说明完整。

本轮保留旧构建文件，Vite 配置使用 `emptyOutDir: false`，不会自动清空 `dist`。新 `index.html` 引用本次生成的资源；旧的未引用资源暂留，不能将目录内文件数量当作当前源码版本数。

## 案例扩展

新增 `public/data/projects/<case-id>/manifest.json` 和资料目录，再向 `catalog.json` 登记一条记录，即可进入案例选择器。`domainContext.js` 中已有三案例是离线兜底，不需要复制新增一份注册常量。页面“新建案例”与资料上传尚未实现。

工作区按 `案例 + 模型项目 + 尺度配置` 隔离。未接入资料的新案例应显示空资料/待接入状态，不能借用旧示例站点、断面、参数或结果。`capabilities: true` 只表示功能形态，不代表当前已能执行计算。

业务说明与页面逻辑见上一级目录的 `使用说明.md`；案例目录和新增流程见 `案例包规范.md`；资料边界见 `数据目录说明.md`。

## 路径约定

- 源码和清单不得写死开发者电脑的盘符或用户目录。
- 静态资源通过统一资源解析入口结合 `import.meta.env.BASE_URL` 加载，避免部署到站点子目录时 `/data/...` 失效。
- 后端地址与静态资源地址分开配置；本阶段后端保持关闭。只有同时设置 `VITE_ENABLE_MODEL_BACKEND=true` 与 `VITE_MODEL_API_BASE` 才可能提交任务；单独设置地址不启用后端。
- JSON 路径检查：`node scripts/normalize_json_resource_paths.mjs`；默认只读，`--write` 才会修改旧资源引用。
- 资料工具路径使用脚本自身位置、显式参数或环境变量，不要求原始资料与前端始终放在同一台电脑的固定盘符。

可迁移不等于完全离线。目前地图文字仍请求 MapLibre 示例字体服务；本轮未提供本地字体资源，断网时地图标注可能缺失。原始资料转换环境与浏览器测试依赖也需要在需要时单独配置，不属于前端启动依赖。
